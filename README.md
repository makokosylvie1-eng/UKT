## 📌 Description du Projet
**UniKin Token (UKT)** est une application décentralisée (DApp) reposant sur un jeton ERC-20 déployé sur le réseau de test **Ethereum Sepolia**. Le projet simule des paiements et des services au sein du campus de l'Université de Kinshasa (photocopies, frais de bibliothèque, robinet/faucet de test) de manière entièrement décentralisée (Zero-Backend).

---

## 🛠️ Stack Technique & Architecture
- **Smart Contract** : Solidity (Standard ERC-20 OpenZeppelin)
- **Frontend** : Angular (Standalone Components)
- **Librairie Web3** : Ethers.js (v6)
- **Portefeuille** : MetaMask
- **Gestion des Données** : Blockchain Sepolia pour le registre des transactions + `localStorage` pour la cartographie des profils étudiants (respect de la vie privée).
